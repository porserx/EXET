# EXET

**EXET** 是一个原生 Windows 浏览器。窗口、标签、地址栏、工具栏和设置页全部由原生控件绘制；网页内容由嵌入式 Chromium 内核渲染。

**版本：1.0.52**

版本策略：当前为 **1.0.28**；以后每次功能发布把最后一位加 **3**（1.0.31、1.0.34……）。当前显示版本存储在 `native/MicaBrowser.WinUI/version.txt`；发布前可运行 `.\version.ps1 -Bump` 自动递增。  
**作者：PorserX & EXET Team**

- 新版彩色波浪应用图标已去掉白色底板，使用透明背景
- 应用图标已同步到 EXE、快捷方式和关于页面


## 立即使用

主程序：

```text
%LOCALAPPDATA%\Programs\EXET Browser\EXET.exe
```

也可以使用根目录的 `Start EXET.vbs`，或桌面上的 **EXET** 快捷方式。快捷方式通过 VBS 静默启动，不会闪控制台窗口。

## Windows 安装包

安装程序：

```text
dist\EXET-Setup-1.0.19.exe
```

- 按当前用户安装，无需管理员权限
- 默认目录：`%LOCALAPPDATA%\Programs\EXET Browser`
- 自动创建桌面和开始菜单快捷方式
- 带卸载程序
- 安装时检测 WebView2 Runtime，缺失时自动安装
- 重新构建安装包：`installer\build-installer.ps1`

### 支持的系统

- **Windows 10 1809（Build 17763）或更新版本，64 位 x64**
- **Windows 11，64 位 x64**
- 不支持 Windows 7 / 8 / 8.1
- 不支持 32 位系统
- 不支持 ARM64 原生运行（当前安装包只包含 x64）
- 需要 Microsoft Edge WebView2 Runtime（安装程序会自动安装）
- 安装包未做商业代码签名，Windows SmartScreen 可能提示“未知发布者”

## 特性

### 默认主页：Litestart

- 默认打开 [Litestart](https://xingyuefox.github.io/Litestart/) 新标签页
- Litestart 是一个开源的类原生起始页，支持多搜索引擎、网站捷径、时钟、静态/动态壁纸和布局自定义
- 项目地址：[XingYueFox/Litestart](https://github.com/XingYueFox/Litestart)
- 可在 **设置 → 常规 → 默认主页** 修改为任意网页 URL
- **关闭后重新打开时恢复标签页**：设置中独立开关，默认关闭；开启后在正常关闭窗口时保存标签和活动标签
- 旧版 EXET 原生主页及相关背景/问候/快捷入口设置已删除
- Litestart 的个性化在其页面设置中完成，EXET 不复制或限制它的功能


### 标签与无痕模式

- 水平标签和左侧垂直标签共用同一组页面状态
- 标签切换时，选中遮罩以非线性动画移动到目标标签
- 水平标签与垂直标签互相切换时带展开/收起动画
- 可在 **设置 → 外观 → 界面动画速度** 调整动画时长，设为 0 关闭动画
- 垂直标签支持折叠为**仅图标模式**
- 垂直标签栏宽度可在 **设置 → 常规 → 标签与性能** 调整（180–420 px）
- 垂直标签栏使用透明云母背景，直接透出窗口材质
- 垂直标签栏顶部有收起/展开按钮
- **无痕标签页**：独立临时浏览器配置，不写入历史记录、不保存密码、不加载扩展；关闭程序后临时配置会被清理
- 快捷键：`Ctrl+T` 新建标签，`Ctrl+Shift+N` 新建无痕标签，`Ctrl+W` 关闭标签



### 外观

- 跟随系统 / 浅色 / 深色
- **夜间模式**：强制深色外壳，并让支持 `prefers-color-scheme` 的网站使用深色配色
- 增强夜间模式会对没有深色主题的网页应用深色转换；已经提供深色背景的网站不会被二次反色
- 深色/夜间模式使用深色云母着色，保留系统材质纹理，同时避免部分显卡与壁纸下发灰、发白

## 构建

关闭正在运行的 EXET 后：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

或双击 `Build EXET.cmd`。

构建产物：

```text
%LOCALAPPDATA%\Programs\EXET Browser\EXET.exe
```

发布版为自包含 win-x64，包含 .NET 运行时和 Windows App SDK。系统需要 Windows 11，以及可用的 Chromium 浏览器内核运行时。

安装目录使用当前用户的 `%LOCALAPPDATA%\Programs\EXET Browser`，而不是文档目录。部分安全软件会把从文档目录启动的未签名程序误判并阻止其写入数据目录；使用用户 Programs 安装目录可以避免这类启动失败。

桌面快捷方式指向安装目录内的 `Launch EXET.vbs` 启动器，而不是直接启动未签名的 EXE，用于绕开 Windows SmartScreen 对直接 shell 启动未签名程序的拦截，也不会闪控制台窗口。直接双击 `EXET.exe` 仍可能触发 SmartScreen。若安全软件仍然拦截，请将 `%LOCALAPPDATA%\Programs\EXET Browser\EXET.exe` 加入信任区。

## 本地数据

```text
%LOCALAPPDATA%\EXET
```

包含设置、历史记录、收藏夹、扩展、密码（DPAPI 加密）和浏览器配置。删除该目录可完全重置。

## 已知限制

- 不提供账号同步、集合和会话恢复
- 密码管理器只保存在当前 Windows 用户，不做云同步
- 夜间模式只改变浏览器外壳和支持深色媒体的网站，不强制重绘所有网页
- 广告拦截是请求级过滤，不注入完整页面元素隐藏规则
- 部分网站和第三方扩展主页可能依赖其自身的浏览器扩展环境
- EXET 当前没有商业代码签名证书。Windows SmartScreen 或第三方安全软件仍可能对未签名程序弹出提示；可选择“更多信息 → 仍要运行”，或将 `%LOCALAPPDATA%\Programs\EXET Browser\EXET.exe` 加入信任区
- 如果按钮看起来被其他窗口挡住，请检查游戏加加 / GamePP 等置顶悬浮窗
